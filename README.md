# 안개 열차 — 도윤 에피소드

〈다음 역〉 프로젝트의 2D 횡스크롤 감성 내러티브 웹 게임 데모입니다. 이름 없는 열차에서 도윤을 만나고, 작업실에 남은 네 기억을 살펴보며 끝내지 못한 노래와 그 노래가 닿은 삶을 따라갑니다.

기획 의도는 **잘 이별하는 방법**입니다. 하지 못한 말과 남은 상처를 지워 주거나 상대의 용서를 확정하지 않습니다. 현재 플레이 범위는 도윤 에피소드입니다. 배경과 캐릭터에는 사용자 제공 이미지와 GPT 이미지 생성 도구로 제작한 시안을 사용했습니다.

## 실행

Node.js 18 이상에서 이 폴더를 열고 다음 명령을 실행합니다. 별도 패키지 설치는 필요 없습니다.

```sh
node preview.mjs
```

브라우저에서 [게임](http://127.0.0.1:4173/) 또는 [UI 배치 편집기](http://127.0.0.1:4173/ui-editor.html)를 엽니다. 서버를 종료하려면 터미널에서 Ctrl+C를 누릅니다. 실행 서버는 기본적으로 이 컴퓨터의 loopback 주소에만 바인딩됩니다. 정적 파일 호스팅을 사용할 경우 dist 폴더 전체를 함께 제공하세요.

게임 실행에 외부 API 호출, API 키, 계정 로그인, 비밀 토큰은 필요하지 않습니다. 음악은 브라우저의 Web Audio로 생성하며, 사용자 입력 후 소리가 재생됩니다. 이미지와 스크립트는 저장소 안의 로컬 파일을 사용합니다.

## 조작

- 좌우 방향키 또는 A/D: 이동
- E 또는 Enter: 조사·대화
- Enter/Space: 대화 진행, 선택한 버튼 실행
- Esc: 일시정지 메뉴
- 일부 터치 환경: 화면 이동·조사 버튼

작업실의 네 기억은 자유 순서로 살펴볼 수 있습니다. 타이틀의 이어서 걷기는 유효한 진행 저장이 있을 때 활성화됩니다. 종료 메뉴는 브라우저 탭을 강제로 닫지 않고 저장을 유지하는 종료 화면으로 이동합니다.

## UI 배치 편집기

실제 게임을 가운데 미리보기로 사용합니다. 요소를 클릭하거나 왼쪽 목록에서 선택하고 노란 **이동 손잡이**를 끌어 옮기세요. 대사창, 화자, 본문, 계속 버튼, 선택지, HUD, 기억창, 메뉴, 타이틀 등을 따로 조정할 수 있습니다. X/Y·크기·글자크기·줄간격, 화면 크기·확대, 실행취소·다시실행, 초기화와 JSON 가져오기/내보내기를 제공합니다. 이미지 라벨은 원본 비율을 유지한 크기로 조절합니다.

‘배치 편집’과 ‘플레이 확인’을 전환할 수 있습니다. 편집기 iframe에서는 새 게임·설정 변경을 포함해 게임 진행을 저장하지 않습니다. ‘게임에 적용’은 같은 주소의 브라우저에 UI 레이아웃을 저장하며, 소스 파일 수정이나 웹 배포가 아닙니다. 완성한 배치는 JSON 파일로 전달·보관할 수 있습니다.

## 브라우저 저장

서버로 전송하지 않는 localStorage를 사용합니다. 저장 공간은 브라우저와 출처(주소·포트)별로 구분됩니다. 다른 브라우저나 주소로 이동하면 같은 저장이 보이지 않을 수 있습니다.

| 키 | 용도 |
| --- | --- |
| next-station-doyun-v1 | 게임 진행·설정 |
| misttrain-ui-layout-v1 | 게임에 적용한 UI 배치 |
| misttrain-ui-draft-v1 | 편집 초안 |

이 저장소에는 플레이어의 실제 브라우저 저장 데이터가 포함되지 않습니다. ‘게임 적용 해제’는 UI 배치만 제거하고 진행 저장은 유지합니다. 브라우저 저장이 제한돼도 UI 편집과 JSON 파일 보관은 가능하지만 브라우저 저장 버튼은 실패할 수 있습니다.

## 구성과 확인 범위

- dist/: 게임, UI 편집기와 이미지 전체
- preview.mjs: Node.js 기본 모듈만 사용하는 로컬 정적 서버
- .gitignore: 비밀 설정·계정/세션 정보·제작 중간물·로그 제외 규칙

게임 진행, 저장 분리, JSON 검증과 편집기 포인터 이벤트·좌표 처리에 대한 자동 검사를 수행한 버전입니다. 실제 브라우저·모바일에서의 화면/포인터·오디오 품질은 추가 확인이 필요합니다.
